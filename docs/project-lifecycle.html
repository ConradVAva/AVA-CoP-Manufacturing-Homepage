Section G

Project lifecycle guidance from pursuit through delivery

Use the lifecycle stages below to align manufacturing domain work with the team’s existing delivery governance and repository documentation.

Presales

Shape the story, frame value hypotheses, qualify scope, and build confidence in the transformation path.

Outputs: pursuit messaging, qualification notes, early capability map, initial roadmap.

Envision / Discovery

Confirm business priorities, current-state pain points, future-state principles, and the baseline architecture and data needs.

Outputs: workshop findings, target scenarios, scope options, decision log.

Analysis

Translate the vision into requirements, process design, backlog structure, integration boundaries, and delivery sequencing.

Outputs: process design packs, prioritized backlog, release themes, dependency view.

Delivery

Build, validate, deploy, and stabilize the solution while preserving change management, quality, and measurable business outcomes.

Outputs: working increments, test evidence, cutover readiness, adoption plan, support model.
