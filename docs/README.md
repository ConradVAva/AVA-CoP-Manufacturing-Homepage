# OctoAcme Project Management Docs

## Overview
OctoAcme manages cross-functional work through a customer-first, iterative project management approach with clear ownership, measurable outcomes, and continuous learning. The project lifecycle moves from initiation and planning through execution, release, and retrospective improvement. Project Managers coordinate delivery, risks, dependencies, schedules, and communication; Product Managers define outcomes and priorities; developers and QA deliver and validate quality.
